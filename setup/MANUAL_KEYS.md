# יצירת API Keys ידנית — 10 דקות

## כתובת
https://platform.claude.com/settings/keys

## לכל workspace:
1. לחץ "+ Create key"
2. שם: `key-{workspace-name}` (ראה טבלה)
3. לחץ Add
4. **העתק את ה-key מיד** — לא יוצג שוב
5. הדבק ב-workspaces_created.json
